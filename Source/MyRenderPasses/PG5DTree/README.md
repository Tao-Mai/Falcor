# PG5DTree 实现与实验报告

## 实现

Lafortune 和 Willems 的论文把三维空间位置和二维方向一起做自适应细分，使用缓存的入射辐亮度做重要性采样和控制变量。这里用固定的世界空间体素网格和逐体素方向直方图表示同一类五维信息。默认网格为 `16³`，每格有 `8×4` 个方向箱。训练与查询缓冲共占约 4.08 MiB，索引可直接在 GPU 上计算。 [原论文 §2–3](https://graphics.cs.kuleuven.be/publications/A5TTRTVOMCRT/index.html)

缓存服务于 `vbuffer` 主命中的第一段连续反射。可用表面是具有漫反射分量的粗糙、不透明 Standard 或 PBRTDiffuse 三角面。以材质着色法线为轴，在同时满足几何反射侧约束的锥内按方位角和归一化的 `cos²θ` 分箱。在截断余弦 PDF `q` 下，每个方向箱的概率都是 `1/B`，其中 `B` 是每体素的箱数。

一次渲染仍从每个像素发出一条路径。训练复用首段之后的路径后缀，按 `q/p` 对后缀辐亮度加权平均。这里的 `p` 是实际采样的立体角 PDF。次顶点 NEE 和后续反弹进入训练，首段直接命中的发光面与环境贡献单独累加。射线阶段读取上次发布的快照，并用 32 位整数原子操作更新训练缓冲。预热结束后，计算着色器定期由训练统计生成箱内平均 RGB、亮度 CDF 和体素平均 RGB。后续帧读取新快照，支持的几何变换、材质、照明或配置变化会清空训练。 [射线着色器](PG5DTree.rt.slang) · [更新着色器](UpdateRadianceCache.cs.slang) · [Falcor 调度](PG5DTree.cpp)

- **自适应重要性采样。** 以缓存亮度选择方向箱，再从箱内抽样。与 BSDF 采样按 `guideMix` 混合，得到 `p = (1 − α) pBSDF + α pguide`。散射权重以及发光网格 NEE 和散射命中灯光的 MIS 均使用这个混合 PDF。
- **控制变量。** 以缓存辐亮度乘 Lambert 漫反射项构造代理 `g`。其积分等于体素平均 RGB 乘当前漫反射反照率，再乘锥内余弦质量 `1 − zmin²`，其中 `zmin` 是反射锥中最小的方向余弦。在实际样本上加 `cvStrength × (∫g dω − g/p)`。由于代理位于连续采样 PDF 的支持域内，且从抽样前的快照取得，校正的条件期望为零。带符号的线性 RGB 进入累计。

## 配置

在 `createPass("PG5DTree", {...})` 的属性字典或渲染面板中设置。已创建的实例也接受 `set_properties()`。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `enableGuiding` | `false` | 开启自适应重要性采样 |
| `enableControlVariate` | `false` | 开启控制变量 |
| `guideMix` | `0.5` | 引导分支概率，范围 0–0.9 |
| `cvStrength` | `0.5` | 控制变量系数，范围 0–1 |
| `minRoughness` | `0.25` | 启用缓存的最低材质粗糙度 |
| `gridResolution` | `16` | 每个空间轴的体素数，范围 1–32 |
| `directionResolution` | `[8, 4]` | 方位角和余弦方向的箱数，乘积最多 64 |
| `warmupFrames` | `8` | 发布首份快照前的训练帧数，0 表示首帧结束后发布 |
| `updateInterval` | `4` | 发布快照的间隔帧数 |
| `minCellSamples` | `32` | 体素开始参与估计所需的训练样本数 |
| `seed` | `0` | 逐像素随机序列的起始样本编号 |
| `maxBounces` / `computeDirect` / `useImportanceSampling` | `6` / `true` / `true` | 基线的反弹数、直接光和 BSDF 采样配置 |

## 实验设置

使用 RTX 2070（驱动 610.88），在 Vulkan Release 下无窗口渲染，分辨率 320×180，固定像素中心，最多 6 次间接反弹。比较基线、仅引导、仅控制变量和两者同时开启。每组使用 8 个种子，每个种子从空缓存起跑，测到 128 spp。同一轮对照共用种子并轮换执行顺序。参考图使用另一个种子，以关闭两种方法的 `PG5DTree` 累计 4,096 spp。

场景一是仓库的 CornellBox。场景二由实验脚本生成，向上发光的面光源下方有遮挡板，主要通过顶棚反射照亮室内。直接光占比用 768 spp 的 0 次间接反弹参考估算。MSE 在累计后的线性 RGB 上计算。

GPU 时间计入 `VBufferRT` 和 `PG5DTree`。每个模式先执行一次管线预编译，再重新设置种子并清空累计和缓存后开始计时。因此计时包含算法的预热帧、清空训练缓冲和缓存更新。各个 spp 检查点取八轮 MSE 的均值和八轮累计 GPU 时间的中位数。等时间对照取基线达到 16、32、64 spp 的中位时长，在各模式的平均 MSE 与中位 GPU 时间曲线上做对数插值。

间接光约占图像平均亮度的 8.7%。由两份 2,048 spp 参考图的差异估算，4,096 spp 参考的残余噪声 MSE 为 `5.18e-6`。

### 分析与验证

- **引导贡献了主要收益。** 64 spp 下，仅引导将两个场景的 MSE 分别降低 36.6% 和 47.1%。两者同时开启时，降幅为 39.3% 和 48.7%。按各场景最大 GPU 预算对齐，同时开启的降幅为 17.9% 和 30.7%，略高于仅引导的 15.9% 和 30.4%。
- **控制变量单开在同 spp 下有效。** 64 spp 时两个场景分别降低 17.6% 和 16.7%。在最大 GPU 预算下，CornellBox 的 MSE 增加 2.1%，遮挡房间的 MSE 降低 1.1%，训练和查询的开销抵消了大部分收益。最短预算下，两种方法同时开启的 MSE 在两个场景分别增加 11.4% 和 0.6%。
- **基线与亮度检查。** 12 spp 的对照测试中，关闭功能的 `PG5DTree` 在 6 次间接反弹下与 `MyPathTracer` 逐值一致。0 次间接反弹时，两项功能自动跳过，最大绝对差为 `5.96e-8`。128 spp 时，各模式跨八轮的平均亮度相对参考的偏差绝对值均小于 0.05%。每轮启用缓存的 128 帧中记录到 31 次快照发布。

这些结果对应主命中引导、默认缓存分辨率和两组静态场景。D3D12 在本机启动时创建图形设备失败，运行验证使用 Vulkan。

## 复现

在已加载 MSVC 环境的 PowerShell 中从仓库根目录运行。已有 CLion 构建关闭了着色器复制，用 `FALCOR_DEVMODE=1` 从源码加载。Mogwai 的内嵌 Python 需要 NumPy，下面从兼容的本机 Python 3.10 环境取得其安装目录。

```powershell
cmake --build build/clion-release --config Release --target PG5DTree MyPathTracer Mogwai
$env:FALCOR_DEVMODE = '1'
$env:PYTHONPATH = python -c 'from pathlib import Path; import numpy; print(Path(numpy.__file__).resolve().parents[1])'
& ./build/clion-release/bin/Release/Mogwai.exe --headless --device-type vulkan --width 320 --height 180 --script scripts/my_graph/benchmark_pg5dtree.py | Out-Host
```

逐次误差、GPU 时间和参考图噪声估计写入 `build/pg5dtree-experiment/results.json`，线性图像写入同目录的 NPZ 文件。设置 `PG5DTREE_SCENE=CornellBox` 或 `PG5DTREE_SCENE=IndirectRoom` 可以单独复现实验。 [实验脚本](../../../scripts/my_graph/benchmark_pg5dtree.py) · [本次原始数据](../../../build/pg5dtree-experiment/results.json)
